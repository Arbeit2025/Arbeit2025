# Arbeit

大学生として学びながら、Python / Flask で小さな Web アプリを作っています。
*I'm a university student building small web apps with Python and Flask.*

## About

- 技術：Python / Flask / SQLite / HTML / CSS / JavaScript
  *Tech: Python / Flask / SQLite / HTML / CSS / JavaScript*
- 関心：学習ログと学習支援、多言語翻訳ツール
  *Interests: learning logs and learning support, multilingual translation tools*
- 方針：小さくてシンプルな道具を、実際に使える形まで作る
  *Approach: building small, simple tools all the way to something actually usable*

## Featured Projects

### [studylog](https://github.com/Arbeit2025/studylog)

Flask + SQLite で作った学習ログアプリ。学習前の計画と学習後の振り返りを記録し、前後の変化や合計学習時間・集中度・理解度の推移を確認できます。

*A study log app built with Flask and SQLite. It records plans before studying and reflections afterwards, so you can review changes over time, total study time, focus, and understanding.*

- Live: https://studylog1.onrender.com/

### [zhtranslate](https://github.com/Arbeit2025/zhtranslate)

多言語の文章を現代中国語へ翻訳する、精度優先のローカル翻訳ワークベンチ。文ごとに `READY / REVIEW / HOLD` の検査結果を返し、曖昧な箇所を流暢さで隠さないことを大切にしています。

*An accuracy-first local translation workbench that translates text from multiple languages into modern Chinese. Each sentence gets a `READY / REVIEW / HOLD` check result — ambiguous parts are flagged, not hidden behind fluent output.*

### [cocoletter](https://github.com/Arbeit2025/cocoletter)

Flask + SQLite のシンプルなメモアプリ。短い文章を保存・一覧表示・削除できる、自分用のメモ置き場です。

*A simple memo app built with Flask and SQLite — a personal place to save, list, and delete short notes.*

### [minigame](https://github.com/Arbeit2025/minigame)

Flask + SQLite で作った、自作ゲームだけを集めたミニゲームポータル。第1弾は候補を登録して回すルーレット抽選です。

*A mini-game portal built with Flask and SQLite, collecting only games I made myself. The first title is a roulette draw where you register your own candidates.*

- Live: https://minigame-b1qp.onrender.com/

### 翻訳・Wiki 系ツール / Translation & Wiki Tools

Wikipedia と翻訳をめぐる、小さな道具のシリーズです。
*A series of small tools around Wikipedia and translation.*

- [volapuktranslate](https://github.com/Arbeit2025/volapuktranslate) — ヴォラピュク語向けの精度優先翻訳ツール。zhtranslate の前作にあたります
  *Accuracy-first translation for Volapük — the predecessor of zhtranslate.*
- [zhtranslate](https://github.com/Arbeit2025/zhtranslate) — 現代中国語への精度優先翻訳ワークベンチ。前作の思想を引き継いだ後継です
  *Accuracy-first translation workbench for modern Chinese — its successor.*
- [wikitranslate](https://github.com/Arbeit2025/wikitranslate)（Wikihonyaku）— 英語版と日本語版の Wikipedia を比べ、日本語版がない・情報量が少ない記事（補完候補）を探します（[公開ページ](https://arbeit2025.github.io/wikitranslate/)）
  *Compares English and Japanese Wikipedia to find articles that are missing or thin in Japanese.*
- [wikitransgeo](https://github.com/Arbeit2025/wikitransgeo)（WikiTranslate Lite - Geography）— 地理（村・集落・町・川・山・島・湖）に絞って、日本語版がない記事を探す試作版です（[公開ページ](https://arbeit2025.github.io/wikitransgeo/)）
  *A geography-focused variant for finding articles missing in Japanese Wikipedia.*
- [wikisourcesearch](https://github.com/Arbeit2025/wikisourcesearch)（WikiSource Scout）— Wikipedia を書く前の参考文献・一次資料探しと、引用の下書き作成を助けます（[公開ページ](https://arbeit2025.github.io/wikisourcesearch/)）
  *Helps find references and primary sources before writing Wikipedia articles, and drafts citations.*
- [wikiImagesearch](https://github.com/Arbeit2025/wikiImagesearch)（WikiImage Finder）— Wikimedia Commons から Wikipedia で使いやすい画像を探します。ライセンス情報付きです（[公開ページ](https://arbeit2025.github.io/wikiImagesearch/)）
  *Searches Wikimedia Commons for images usable on Wikipedia, with license information.*
