# Arbeit

大学生として学びながら、Python / Flask で小さな Web アプリを作っています。
*I'm a university student building small web apps with Python and Flask.*

## About

- 技術：Python / Flask / SQLite / HTML / CSS / JavaScript
  *Tech: Python / Flask / SQLite / HTML / CSS / JavaScript*
- 関心：学習ログと学習支援、多言語翻訳ツール
  *Interests: learning logs and learning support, multilingual translation tools*
- 方針：小さくてシンプルな道具を、実際に使える形まで作る
  *Approach: building small, simple tools all the way to something actually usable*

## Featured Projects

### [studylog](https://github.com/Arbeit2025/studylog)

Flask + SQLite で作った学習ログアプリ。学習前の計画と学習後の振り返りを記録し、前後の変化や合計学習時間・集中度・理解度の推移を確認できます。

*A study log app built with Flask and SQLite. It records plans before studying and reflections afterwards, so you can review changes over time, total study time, focus, and understanding.*

- Live: https://studylog1.onrender.com/

### [zhtranslate](https://github.com/Arbeit2025/zhtranslate)

多言語の文章を現代中国語へ翻訳する、精度優先のローカル翻訳ワークベンチ。文ごとに `READY / REVIEW / HOLD` の検査結果を返し、曖昧な箇所を流暢さで隠さないことを大切にしています。

*An accuracy-first local translation workbench that translates text from multiple languages into modern Chinese. Each sentence gets a `READY / REVIEW / HOLD` check result — ambiguous parts are flagged, not hidden behind fluent output.*

### [cocoletter](https://github.com/Arbeit2025/cocoletter)

Flask + SQLite のシンプルなメモアプリ。短い文章を保存・一覧表示・削除できる、自分用のメモ置き場です。

*A simple memo app built with Flask and SQLite — a personal place to save, list, and delete short notes.*
